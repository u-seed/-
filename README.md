# Каспи: люстры и бра

PWA для поиска люстр и бра на Kaspi Магазине подешевле (флиппинг, ремонт).

**Приложение:** https://u-seed.github.io/-/

## Что умеет
- **Каталог:** люстры / бра, фильтр по диаметру (40, 50, 60, 80 см…), цена (по умолчанию до 100 000 ₸), поиск, сортировка, метки «🆕 новая сегодня» и «↓ подешевела».
- **Найти такую же:** вставляешь ссылку на карточку Kaspi (эталон) → список таких же и похожих по фото, от дешёвых к дорогим, с разницей к цене эталона и другими размерами.
- **Избранное:** сохраняется на телефоне, показывает изменение цены с момента добавления.

## Как обновляются данные
`scripts/parse.py` запускается в GitHub Actions: только вручную (Actions → parse-kaspi → Run workflow), по расписанию не запускается. Результат — `data.json` (цены, диаметры, число ламп, хэши фото).
Поле `ref_url` при запуске необязательное, его можно оставить пустым.
Если категория не нашлась автоматически, смотри `parse-log.txt` и папку `debug/`.

## Установка на телефон
Settings → Pages → ветка main / root. Android Chrome → меню → «Добавить на главный экран».
