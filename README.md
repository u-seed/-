# Каспи: люстры и бра

PWA для поиска люстр и бра на Kaspi Магазине подешевле (флиппинг, ремонт).

**Приложение:** https://u-seed.github.io/-/

## Что умеет
- **Каталог:** люстры / бра, фильтр по диаметру (40, 50, 60, 80 см…), цена (по умолчанию до 100 000 ₸), поиск, сортировка, метки «🆕 новая сегодня» и «↓ подешевела».
- **Найти такую же:** вставляешь ссылку на карточку Kaspi (эталон) → список таких же и похожих по фото, от дешёвых к дорогим, с разницей к цене эталона и другими размерами.
- **Избранное:** сохраняется на телефоне, показывает изменение цены с момента добавления.

## Как обновляются данные
`scripts/parse.py` запускается в GitHub Actions только вручную: Actions → parse-kaspi → Run workflow.
Поля запуска: комната для люстр («гостиная» по умолчанию, «любая» — без фильтра), цена от и до, режим:
- **resume** (по умолчанию) — список из прошлого запуска не обходится, догружаются фото-хэши, характеристики (сначала люстры от 25 000 ₸), затем надписи на фото. Если data.json пуст, сам перейдёт в full.
- **full** — обойти весь список Kaspi заново (долго, ~80 мин): обновит цены, добавит новые карточки.

Прогресс сохраняется в `data.json` по ходу работы. Если не хватило времени, запусти ещё раз.

## Откуда берётся диаметр
Приоритет: поле «Диаметр» в карточке → надпись на фото («Диаметр 80 см», читается через tesseract) → код модели в ссылке (ABC 1888-800 = 80 см) → «длина = ширина» в характеристиках (≈) → число из названия (≈). Источник виден в приложении: ≈ — приблизительно, 📷 — прочитано с фото.

Если категория не нашлась автоматически, смотри `parse-log.txt` и папку `debug/`.

## Установка на телефон
Settings → Pages → ветка main / root. Android Chrome → меню → «Добавить на главный экран».
